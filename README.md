# 🤖 Discord Bot

Um bot multifuncional para servidores Discord desenvolvido em Python utilizando Discord.py.

## ✨ Funcionalidades

### 🎫 Sistema de Tickets
- Criação automática de tickets
- Fechamento de tickets
- Organização por categorias
- Registro de ações

### 🎉 Sistema de Sorteios
- Criação de sorteios
- Participação automática
- Encerramento automático
- Escolha de vencedores

### 🛡️ Sistema de Moderação
- Advertências
- Controle de usuários
- Registro de ações administrativas

### 🔔 Sistema de Notificações
- Envio de avisos
- Sistema de anúncios
- Configuração de canais específicos

### 👤 Sistema de Perfil
- Perfil de usuário
- Estatísticas
- Informações armazenadas em banco de dados

### 🎖️ Sistema de Cargos
- Gerenciamento automático de cargos
- Cargos bônus
- Controle de permissões

---

## 🛠️ Tecnologias Utilizadas

- Python 3.13
- Discord.py
- PostgreSQL
- Asyncio
- JSON

## 🚀 Instalação

Clone o repositório:

```bash
git clone https://github.com/eusants01/discord-bot.git
```

Entre na pasta:

```bash
cd discord-bot
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Configure o token do bot e execute:

```bash
python main.py
```
